# 건강식 지도

건강식 지도는 장소와 메뉴를 지도에서 찾아 비교하는 한국어 웹 앱입니다. 검색, 카테고리
필터, 지도 마커, 장소 상세, 길찾기 링크, 그리고 장소·메뉴 제안 화면을 제공합니다.

않습니다. 앱은 구성된 발견용 데이터베이스의 제한된 서버 API만 읽으며, 브라우저는 공개 DTO만
