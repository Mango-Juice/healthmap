# 보안과 공개 경계

브라우저에 전달해도 되는 값만 `NEXT_PUBLIC_` 환경 변수로 설정합니다. 관리자 키, 데이터 가져오기
자격 증명, 원본 자료, 제안 검토 기록은 서버와 비공개 운영 환경에만 둡니다. 비밀값이나 개인 정보를
이슈, 로그, 스크린샷, 테스트 입력에 포함하지 마세요.

장소·메뉴 제안은 제한된 크기의 텍스트와 HTTPS 링크를 받으며 자동으로 공개 데이터에 반영되지
않습니다. 제안 내용과 링크는 신뢰할 수 없는 입력으로 취급합니다.

보안 문제를 신고(report)할 때는 재현에 필요한 최소 정보만 사용하고 비밀값·개인정보·원본 데이터를
공개 채널에 게시하지 마세요. 이 저장소는 현재 공개 보안 연락처(public security contact)를 제공하지
않으므로, 공개 이슈를 기밀 제보 채널로 간주하면 안 됩니다.

이 저장소의 공개 경계는 [LICENSE](../LICENSE)의 소스 열람 조건과
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)의 의존성 고지를 따릅니다. 이 경계는 외부 자료의
이용 권리나 서비스 데이터의 사실성을 보증하지 않습니다.
